# Tech Stack - Ting

Choosing the following technologies for Ting focuses on minimalist performance, developer productivity, and "app-like" user experience.

## Frontend
| Technology | Usage | Reason |
|---|---|---|
| **Next.js 15** | Framework | App Router, SSR/SSG capabilities, and built-in API routes. |
| **React 19** | UI Library | Modern component model and hooks. |
| **Tailwind CSS** | Styling | Rapid UI development with standard utility classes. |
| **Shadcn UI** | Components | Beautiful, accessible, and highly customizable UI parts. |
| **Framer Motion** | Animation | Smooth transitions and interactive micro-animations. |
| **Zustand** | State | Lightweight state management with built-in persistence. |
| **TanStack Query** | Data Fetching | Powerful caching, revalidation, and loading states. |

## Backend & Logic
| Technology | Usage | Reason |
|---|---|---|
| **Next.js API Routes** | API | Seamless integration with the frontend and zero-config deployment. |
| **SQLite** | Database | Zero-latency, zero-cost, and easy portability via file backups. |
| **TypeScript** | Logic | Type safety across the entire stack. |
| **Axios** | HTTP Client | Consistent API for data fetching. |

## DevOps & Tools
| Technology | Usage | Reason |
|---|---|---|
| **next-pwa** | PWA Support | Turns the web app into a downloadable mobile app with offline support. |
| **Docker** | Containerization | Consistent development and production environments. |
| **Makefile** | Automation | Simple, unified entry point for all project tasks. |
| **Sonner** | Notifications | Elegant, lightweight toast notifications. |
| **Lucide React** | Icons | Minimalist and consistent icon set. |
